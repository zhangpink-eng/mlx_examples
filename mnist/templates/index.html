训练参数

模型结构
每层隐藏层的神经元数量。越多 → 模型可以学习更复杂的特征组合，但参数量暴涨、训练变慢、更容易过拟合（记住训练集而非通用规律）。MNIST 这种简单任务 32~128 足矣。
隐藏层数量（总 Linear 层数 = 隐藏层 + 1 输出层）。层数越多 → 模型能表达更抽象的特征层次（如 边缘→形状→数字局部→整体），但梯度在反向传播时容易消失。2~3 层对 MNIST 够了。
训练过程
整个训练集被完整遍历的次数。越多 → 模型有更多机会学习数据中的规律，但超过某个点后 Loss 不再下降（收敛），继续训练只会浪费时间甚至过拟合。通常观察 Loss 曲线不再下降时就可以停。
每次参数更新时喂入的样本数。小 batch（32~64）→ 梯度噪声大但泛化好，等效引入正则化效果。大 batch（512+）→ 梯度方向更准、训练更快，但容易收敛到尖锐最小值（泛化差）。256 是常见折中。
实际值 = 10滑条值，范围 0.001 ~ 1.0。控制每步参数更新的步长。太大 → Loss 震荡甚至发散（跳过了最优点）。太小 → 收敛极慢甚至困在局部最优。SGD 通常 0.01~0.1，Adam 通常 0.0001~0.001。
SGD：经典方法，学习率需要手动调好，简单直接。Adam：自动调整每个参数的学习率，对新手工匠友好、收敛更快更稳，但最终的泛化精度有时略逊于调好的 SGD。
数据与复现
MNIST：经典手写数字识别，简单基线，适合验证模型基本功能。Fashion-MNIST：同尺寸（28×28 灰度）但内容为服装，难度略高，分类更依赖纹理而非简单形状，是替代 MNIST 的更好的现代基线。
控制权重初始化和数据打乱的随机性。种子固定 → 多次运行结果完全可复现。种子不同 → 每次的初始化权重和数据顺序都不同，可用于评估随机性对结果的影响。

为什么需要偏置？
先说直觉：
权重 W = 每个输入像素的重要性（黑不黑、是否在边缘上）
偏置 b = 该神经元的「基础点亮门槛」

具体算给你看：
假装有一层 Linear(2, 3)（2 个输入 → 3 个输出），公式展开：
y₁ = x₁·w₁₁ + x₂·w₁₂ + b₁
y₂ = x₁·w₂₁ + x₂·w₂₂ + b₂
y₃ = x₁·w₃₁ + x₂·w₃₂ + b₃
有 3 个输出（y₁, y₂, y₃），所以有 3 个偏置（b₁, b₂, b₃）。
回到 Linear(784, 32)：有 32 个输出 → 就有 32 个偏置。
再回到 总参数公式：每层参数量 = 输入×输出 + 输出 = 权重数 + 偏置数。

训练循环：①→②→③ 重复 235 次（每 batch 256 张图），遍历完所有训练集后做 1 次④ → 完成一个 epoch
前向：像素值流经每层 Linear+ReLU，最后输出 10 个数字（每类一个得分）
反向：自动求导算出每个参数对 Loss 的梯度（导数），即「往哪调能降低 Loss」
更新：按梯度反方向微调参数。SGD 直接减，Adam 还自适应调整每一步的步长
评估：只用前向传播（不更新参数），对比预测 vs 真实标签算正确率
epoch 间的关系：后一个 epoch 沿用前一个训练好的参数继续微调，层层递进。所以 Loss 应逐轮下降、Accuracy 应逐轮上升。
具体算例 — 从输入到参数更新的完整计算
用一个小网络 Linear(2,3) → ReLU → Linear(3,2) 走完全程，每步都算出具体数值。
输入 x = [0.5, 0.8]，目标类别 = 0（one-hot t = [1, 0]）
初始权重与偏置 — 模型在训练前的「出厂状态」
训练前权重 W 和偏置 b 由 MLX 随机初始化。这里用了一组小数值做演示。
每个 wⱼₖ = 第 k 个输入对第 j 个神经元的影响强度。bⱼ = 第 j 个神经元的「基础激活门槛」。
第1层有 3×2+3 = 9 个参数，第2层有 2×3+2 = 8 个参数，共 17 个。
第1层 W¹（3×2） — 2 个输入 → 3 个隐藏神经元
w¹₁₁=0.1   w¹₁₂=0.2   b¹₁=0.01
w¹₂₁=0.3   w¹₂₂=0.4   b¹₂=0.02
w¹₃₁=0.5   w¹₃₂=0.6   b¹₃=0.03
第2层 W²（2×3） — 3 个隐藏神经元 → 2 个输出（类别 0 和 1）
w²₁₁=0.7   w²₁₂=0.4   w²₁₃=0.9   b²₁=0.04
w²₂₁=0.2   w²₂₂=0.6   w²₂₃=0.3   b²₂=0.05
① 前向传播 — 输入数据流经网络，算出预测结果
前向传播在干什么？把输入 x（2 个像素值）送进网络，每层做一次「加权求和 + 偏置 + 激活函数」，最终输出 2 个得分（每个类别一个分）。
公式 z = W·x + b：每个输出神经元 = 所有输入 × 对应权重的总和 + 偏置。
z¹ = W¹·x + b¹ — 第1层线性变换
z¹₁ = 0.1×0.5 + 0.2×0.8 + 0.01 = 0.05 + 0.16 + 0.01 = 0.22
↑ z¹₁ = 第1个隐藏神经元的原始得分，0.1×0.5 是第1个输入像素的贡献，0.2×0.8 是第2个输入像素的贡献，0.01 是偏置
z¹₂ = 0.3×0.5 + 0.4×0.8 + 0.02 = 0.15 + 0.32 + 0.02 = 0.49
z¹₃ = 0.5×0.5 + 0.6×0.8 + 0.03 = 0.25 + 0.48 + 0.03 = 0.76

a¹ = ReLU(z¹) — 激活函数，砍掉负数
ReLU(x) = max(0, x)，把负数清零、正数保留。这里 z¹ 全部 > 0，所以 a¹ = z¹。
如果 z¹ 中有负数，ReLU 会把它们变成 0，引入非线性，让多层网络不再等价于单层。
a¹ = [0.22, 0.49, 0.76]
↑ 3 个隐藏神经元的激活值，传给第2层

z² = W²·a¹ + b² — 第2层线性变换
第2层把 3 个隐藏特征映射到 2 个输出类别。z²₀ 是「属于类别 0」的得分，z²₁ 是「属于类别 1」的得分。
z²₁ = 0.7×0.22 + 0.4×0.49 + 0.9×0.76 + 0.04
= 0.154 + 0.196 + 0.684 + 0.04 = 1.074
↑ 类别 0 的得分。三个隐藏神经元的贡献分别为 0.154、0.196、0.684。第3个隐藏神经元贡献最大（0.684），因为它激活值最高（0.76）且权重最大（0.9）。
z²₂ = 0.2×0.22 + 0.6×0.49 + 0.3×0.76 + 0.05
= 0.044 + 0.294 + 0.228 + 0.05 = 0.616
↑ 类别 1 的得分，比类别 0 低（0.616 < 1.074），目前模型认为更像类别 0。
Loss 计算 — Softmax + Cross-Entropy，给预测结果「打分」
为什么需要 Softmax？原始得分 z² = [1.074, 0.616] 没有上限、未归一化。Softmax 把它们变成 0~1 之间的概率，总和为 1。
公式 sⱼ = e^zⱼ / Σe^z：先指数化（让大得分更大、小得分更小），再除以总和做归一化。

Cross-Entropy Loss 衡量什么：模型对正确答案给出的概率越低 → Loss 越高。最小化 Loss = 让模型对正确答案越来越自信。
Softmax 归一化：
s₀ = e^1.074 / (e^1.074 + e^0.616) = 2.927 / (2.927 + 1.852) = 0.612
↑ 类别 0 的得分 1.074，指数化后 2.927，占总分 4.779 的 61.2%。这是模型认为「这是 0」的概率。
s₁ = e^0.616 / 4.779 = 1.852 / 4.779 = 0.388
↑ 类别 1 的概率 38.8%。s₀+s₁=1。

Cross-Entropy Loss： L = −Σ tⱼ · log(sⱼ)
真实标签 t = [1, 0]（one-hot），所以 L = −1×log(s₀) − 0×log(s₁) = −log(0.612)
L = −log(0.612) = 0.491
↑ Loss = 0.491。怎么判断高低？如果模型完全瞎猜（50% 对 50%），Loss = −log(0.5) = 0.693。
现在 Loss = 0.491 比 0.693 低，说明模型「有点感觉但还不够」——它认为 0 的概率是 61.2%，比 50% 好，但远不够 100%。
💡 Loss 的作用：它是整个训练过程的「唯一裁判」。反向传播的所有梯度、参数更新的每一步，终极目标都是让这个数字变小。
② 反向传播 — 从 Loss 出发，逐层算出每个参数的梯度
反向传播要回答的问题：每个参数（w 和 b）应该往哪个方向调、调多少，才能让 Loss 下降？
答案就是计算 梯度 ∇：∂L/∂参数。梯度为正 → 参数增大使 Loss 增大 → 应该减小参数。梯度为负 → 参数增大使 Loss 减小 → 应该增大参数。
计算顺序 从后往前：先算输出层，再用链式法则一层层传播到输入层。
输出层梯度： Softmax + Cross-Entropy 的联合导数恰好是 ∂L/∂z²ⱼ = sⱼ − tⱼ
📌 这个公式很漂亮：梯度 = 模型「猜的」(sⱼ) 减去「对的」(tⱼ)。
  正确类（0）：猜了 0.612，应该是 1 → 梯度 = 0.612−1 = −0.388 → 需要提高这个类的得分
  错误类（1）：猜了 0.388，应该是 0 → 梯度 = 0.388−0 = +0.388 → 需要降低这个类的得分
∂L/∂z²₀ = 0.612 − 1 = −0.388
∂L/∂z²₁ = 0.388 − 0 = +0.388

对 W² 的梯度： ∂L/∂w²ⱼₖ = ∂L/∂z²ⱼ × a¹ₖ
链式法则第1步：W² 直接连接输出层，所以 ∂L/∂W² = ∂L/∂z² × a¹（a¹ 是第1层的输出）。
每个 w²ⱼₖ 的梯度 = 「z²ⱼ 的梯度」×「a¹ₖ 的值」。
∂L/∂w²₁₁ = (−0.388) × 0.22 = −0.085  |  ∂L/∂w²₂₁ = 0.388 × 0.22 = 0.085
∂L/∂w²₁₂ = (−0.388) × 0.49 = −0.190  |  ∂L/∂w²₂₂ = 0.388 × 0.49 = 0.190
∂L/∂w²₁₃ = (−0.388) × 0.76 = −0.295  |  ∂L/∂w²₂₃ = 0.388 × 0.76 = 0.295
↑ 第3个隐藏神经元的权重梯度（±0.295）最大，因为它的激活值最大（0.76）——激活值越大的神经元，它的权重调整就越多。
对 b² 的梯度： ∂L/∂b²₀ = −0.388   ∂L/∂b²₁ = 0.388
↑ b² 的梯度直接等于 ∂L/∂z²ⱼ（因为 ∂z²ⱼ/∂b²ⱼ = 1）。

传播到隐藏层： ∂L/∂a¹ₖ = Σ ∂L/∂z²ⱼ × w²ⱼₖ
链式法则第2步：a¹（隐藏层激活值）的梯度 = 所有输出层梯度 × 对应权重的总和。
每个隐藏神经元汇总了它影响到的所有输出神经元的梯度信息。
∂L/∂a¹₁ = (−0.388)×0.7 + 0.388×0.2 = −0.272 + 0.078 = −0.194
∂L/∂a¹₂ = (−0.388)×0.4 + 0.388×0.6 = −0.155 + 0.233 = +0.078
∂L/∂a¹₃ = (−0.388)×0.9 + 0.388×0.3 = −0.349 + 0.116 = −0.233
↑ 第1个隐藏神经元接收来自两个输出神经元的信号：来自类别0的 −0.272（因为 w²₁₁=0.7 大了传过来），来自类别1的 +0.078（通过 w²₂₁=0.2）。
净效果 −0.194，意味着要「降低这个隐藏神经元的贡献来帮助降低 Loss」。

通过 ReLU： ∂L/∂z¹ⱼ = ∂L/∂a¹ⱼ × ReLU'(z¹ⱼ)
ReLU 的导数很简单：输入>0 时导数为 1，≤0 时为 0。这里 z¹ 全部 > 0，所以梯度直接通过、数值不变。
∂L/∂z¹ = [−0.194, 0.078, −0.233]

对 W¹ 的梯度： ∂L/∂w¹ⱼₖ = ∂L/∂z¹ⱼ × xₖ
链式法则到了最底层：W¹ 直接连接输入 x，所以 ∂L/∂W¹ = ∂L/∂z¹ × x（x 是原始输入 [0.5, 0.8]）。
∂L/∂w¹₁₁ = (−0.194)×0.5 = −0.097  |  ∂L/∂w¹₁₂ = (−0.194)×0.8 = −0.155
∂L/∂w¹₂₁ = 0.078×0.5 = 0.039    |  ∂L/∂w¹₂₂ = 0.078×0.8 = 0.062
∂L/∂w¹₃₁ = (−0.233)×0.5 = −0.117  |  ∂L/∂w¹₃₂ = (−0.233)×0.8 = −0.186
对 b¹ 的梯度： ∂L/∂b¹ = [−0.194, 0.078, −0.233]
↑ 至此，全部 17 个参数的梯度都算完了。每个 ∂L/∂w 告诉你：w 增加 1 个单位，Loss 会变化多少。
③ 参数更新 — SGD，沿梯度反方向迈一小步
更新规则：Wnew = W − lr × ∇W
梯度 ∇W 指向 Loss 升高的方向 → 我们朝反方向走 → Loss 下降。
学习率 lr 控制步长：lr=0.1 意味着每步最多移动梯度值的 10%。太小收敛慢，太大可能跳过最优点导致震荡。
注意看梯度符号如何决定调整方向：
第1层 W¹_new：
w¹₁₁：梯度 −0.097（负值）→ 需要增大 w → 0.1 − 0.1×(−0.097) = 0.110 ↑
w¹₁₁: 0.1 − 0.1×(−0.097) = 0.1 + 0.010 = 0.110
w¹₁₂: 0.2 − 0.1×(−0.155) = 0.2 + 0.016 = 0.216
w¹₂₁: 0.3 − 0.1×(0.039) = 0.3 − 0.004 = 0.296
w¹₂₂: 0.4 − 0.1×(0.062) = 0.4 − 0.006 = 0.394
w¹₃₁: 0.5 − 0.1×(−0.117) = 0.5 + 0.012 = 0.512
w¹₃₂: 0.6 − 0.1×(−0.186) = 0.6 + 0.019 = 0.619
b¹_new = [0.01 − 0.1×(−0.194), 0.02 − 0.1×(0.078), 0.03 − 0.1×(−0.233)]
= [0.029, 0.012, 0.053]

第2层 W²_new：
w²₁₁: 0.7 − 0.1×(−0.085) = 0.7 + 0.009 = 0.709
w²₁₂: 0.4 − 0.1×(−0.190) = 0.4 + 0.019 = 0.419
w²₁₃: 0.9 − 0.1×(−0.295) = 0.9 + 0.030 = 0.930
w²₂₁: 0.2 − 0.1×(0.085) = 0.2 − 0.009 = 0.191
w²₂₂: 0.6 − 0.1×(0.190) = 0.6 − 0.019 = 0.581
w²₂₃: 0.3 − 0.1×(0.295) = 0.3 − 0.030 = 0.270
↑ 注意看 w²₁₁ 和 w²₂₁ 的变化：w²₁₁ 梯度 −0.085 → 增大（让类别 0 的得分更高）；w²₂₁ 梯度 +0.085 → 减小（让类别 1 的得分更低）。
b²_new = [0.04 − 0.1×(−0.388), 0.05 − 0.1×(0.388)]
= [0.079, 0.011]
↑ b²₀ 从 0.04 增大到 0.079（调高类别 0 的门槛让预测偏向 0），b²₁ 从 0.05 减小到 0.011（调低类别 1 的门槛让预测远离 1）。
④ 验证 — 用新参数重跑前向，检验参数更新是否有效
把更新后的 17 个参数代入网络，重跑一遍完整的前向传播。如果反向传播算对了、学习率没设太大，新 Loss 应该比旧 Loss 小。
用 W¹_new, b¹_new 重算第1层：
z¹₁ = 0.110×0.5 + 0.216×0.8 + 0.029 = 0.055 + 0.173 + 0.029 = 0.257
z¹₂ = 0.296×0.5 + 0.394×0.8 + 0.012 = 0.148 + 0.315 + 0.012 = 0.475
z¹₃ = 0.512×0.5 + 0.619×0.8 + 0.053 = 0.256 + 0.495 + 0.053 = 0.804
↑ 三个隐藏神经元的得分都有所提升（0.22→0.257, 0.49→0.475, 0.76→0.804），因为大部分权重和偏置都增大了。
a¹_new = [0.257, 0.475, 0.804]

用 W²_new, b²_new 重算第2层：
z²₁ = 0.709×0.257 + 0.419×0.475 + 0.930×0.804 + 0.079
= 0.182 + 0.199 + 0.748 + 0.079 = 1.208
↑ 类别 0 的得分从 1.074 提升到 1.208 ✅ 这正是我们想要的（所有相关权重都增大了）
z²₂ = 0.191×0.257 + 0.581×0.475 + 0.270×0.804 + 0.011
= 0.049 + 0.276 + 0.217 + 0.011 = 0.553
↑ 类别 1 的得分从 0.616 降低到 0.553 ✅ 这正是我们想要的（相关权重都减小了）

新 Softmax：
s₀_new = e^1.208 / (e^1.208 + e^0.553) = 3.347 / 5.086 = 0.658
s₁_new = 1.739 / 5.086 = 0.342
↑ 模型对「这是 0」的把握从 61.2% 提升到了 65.8%，对「这是 1」的怀疑从 38.8% 降到了 34.2%。

新 Loss：
L_new = −log(0.658) = 0.418

L_old = 0.491   →   L_new = 0.418   ✅ Loss 下降了 15%！
一次参数更新就有效果——这个 batch 的 2 张「图」让模型进步了一点点。
整件事串联起来看：
① 输入 x 前向流过网络 → 算出得分 → Softmax 变概率 → Cross-Entropy 给 Loss
② 从 Loss 出发，链式法则逐层往回算梯度（MLX 的 nn.value_and_grad 自动完成）
③ 负梯度方向 × 学习率 → 更新所有参数
④ 用新参数重跑 → Loss 变低了 → 这个 batch 学完了 → 继续下一个 batch

实际代码中 MLX 自动完成所有梯度计算。理解这个流程的意义在于：当训练不收敛时，你能判断是学习率太大（Loss 震荡）、梯度消失（Loss 不动）、还是数据有问题（Loss 下不去）。

数据预处理 — 归一化 Normalization
x_normalized = x_raw / 255.0
MNIST 原始像素值是 0~255 的整数（0=全黑，255=全白），除以 255 归一化到 0.0~1.0。

为什么需要归一化？
① 数值稳定性：不归一化的话，784 个 0~255 的值加权求和后可能达到上万级别，配合初始权重会让输出巨大，经过 softmax 后梯度极小（梯度饱和），模型几乎学不动。
② 公平特征尺度：所有像素的取值范围统一在 [0,1]，每个输入对梯度的贡献量级一致。如果某个特征的取值范围天然比别的大很多，它会主导梯度方向。
③ 加速收敛：归一化后的 Loss 曲面更接近「球形」，梯度下降路径更直接，不会在狭窄山谷中来回震荡。

其他归一化方法：标准化 (x−μ)/σ 让数据均值为 0、方差为 1，同样常用。对于图像，除以 255 是最朴素的归一化，对 MNIST 已经足够。
参数量计算 — 26,506 的来源
默认设置 hidden_dim=32, num_layers=2 的 MLP：

模型结构：Linear(784,32) → ReLU → Linear(32,32) → ReLU → Linear(32,10)

每层参数量公式：权重数 + 偏置数 = input_dim × output_dim + output_dim

逐层计算：
Layer 1（784→32）：784×32 + 32 = 25,088 + 32 = 25,120
Layer 2（32→32）：  32×32 + 32 = 1,024 + 32 = 1,056
Layer 3（32→10）：  32×10 + 10 =   320 + 10 = 330
总计：25,120 + 1,056 + 330 = 26,506
权重 W（蓝色部分）：每层所有输入到所有输出的连接数 = input_dim × output_dim。把 784 个像素映射到 32 个特征需要 784×32 个连接强度。
偏置 b（绿色部分）：每个输出神经元各一个，共 output_dim 个。

调参时参数量变化（举个例子）：
  • hidden_dim=32 → 64：26,506 → 59,210（翻倍以上，因为中间层 32→64 后三层都变大了）
  • num_layers=2 → 3：26,506 → 101,962（多一层 64→64 需要 4,160 个额外参数）
梯度 Gradient — 概念详解
1. 梯度是什么
∇L(W) = [ ∂L/∂w₁, ∂L/∂w₂, ..., ∂L/∂wₙ ]
梯度是一个向量，每个分量是 Loss 对某个参数 wᵢ 的偏导数。
偏导数 ∂L/∂wᵢ 的含义：如果 wᵢ 增加一丁点，Loss 会变化多少。
整个梯度向量 ∇L 的方向 = Loss 上升最快的方向。

2. 为什么朝反方向走
W_new = W − lr · ∇L
梯度指向 Loss 增加最快的方向 → 我们朝反方向（负梯度）走 → Loss 下降。
这就是「梯度下降」这个名字的由来。

3. 一个参数版 — 下山类比
假设模型只有一个参数 w，Loss 曲线 L(w) 像一座山：
  • ∂L/∂w > 0（斜率为正）→ w 在右坡上 → 往左走（减小 w）才能下山
  • ∂L/∂w < 0（斜率为负）→ w 在左坡上 → 往右走（增大 w）才能下山
无论哪种情况，w = w − lr · ∂L/∂w 都正确地把 w 推向山谷。
用 26506 个参数替代一个 w —— 就得到完整的模型更新。

4. MLX 如何自动计算梯度
loss_and_grad_fn = nn.value_and_grad(model, loss_fn)
loss, grads = loss_and_grad_fn(model, X, y)
调用 nn.value_and_grad 后，MLX 框架内部自动构建计算图：
  ① 记录前向传播中每步操作的顺序
  ② 从 Loss 出发，沿计算图反向遍历每一步
  ③ 每步用链式法则乘上局部导数
  ④ 最终每个参数得到对应的梯度值
你不需要手动推导任何一个导数公式 —— 框架全自动完成。
① 前向传播 — Linear 层公式
y = W·x + b
展开写，以 Linear(784, 32) 为例：
y₁ = x₁·w₁₁ + x₂·w₁₂ + ... + x₇₈₄·w₁_₇₈₄ + b₁
y₂ = x₁·w₂₁ + x₂·w₂₂ + ... + x₇₈₄·w₂_₇₈₄ + b₂
⋮
y₃₂ = x₁·w₃₂₁ + x₂·w₃₂₂ + ... + x₇₈₄·w₃₂_₇₈₄ + b₃₂
W：权重矩阵（784×32），每个元素 wⱼₖ 表示第 k 个输入像素对第 j 个输出神经元的影响强度
x：输入向量（784 个灰度值，归一化到 0~1）
b：偏置向量（32 个值），每个输出神经元一个，控制其激活门槛
y：输出向量（32 个值），每个值 = 784 个输入的加权和 + 偏置
作用：把 784 个像素信息压缩成 32 个「高层特征」。
ReLU 激活函数
ReLU(x) = max(0, x)
作用在每层 Linear 之后（输出层之前）：
h = ReLU(W·x + b)
具体行为：把线性层输出的负数全部变成 0，正数保持不变
为什么要用：如果没有 ReLU，多个 Linear 层叠在一起等价于一个 Linear（因为线性变换的复合还是线性）。ReLU 砍掉负数 = 引入非线性，让深层网络真正有意义。
例子：输出 [-5, 1.2, 0, -0.3, 4] → ReLU → [0, 1.2, 0, 0, 4]
它的导数也很简单：x>0 时导数为 1，x≤0 时导数为 0。反向传播计算极快。
损失函数 — Cross Entropy
L = −Σ tᵢ · log(yᵢ)
其中 tᵢ 是真实标签（one-hot，正确类=1，其他=0），yᵢ 是模型预测的概率（softmax 归一化后）

简化理解：因为 tᵢ 只有一个 1（真实类别），公式简化为：
L = −log(模型对正确答案给出的概率)
例子：真实数字是 7，模型预测概率分布为 [0.01, 0.01, 0.02, 0.02, 0.01, 0.03, 0.01, 0.85, 0.02, 0.02]
L = −log(0.85) = 0.16（低 → 预测好）
如果模型对 7 只给出 0.1 的概率：L = −log(0.1) = 2.30（高 → 预测差）
作用：Loss 是整个训练过程的唯一评判标准。反向传播的目标就是让 Loss 越来越小。
② 反向传播 — 链式法则
∂L/∂W = (∂L/∂y) · (∂y/∂W)
链式法则：复合函数的导数 = 外层导数 × 内层导数，一层层往回传

用两层的例子说明信号流：
x → Linear(W₁, b₁) → ReLU → Linear(W₂, b₂) → CrossEntropy(Loss)

反向传播信号流向：
∂L/∂W₂ = ∂L/∂y₂ · ∂y₂/∂W₂ ← 先算输出层的梯度
∂L/∂h = ∂L/∂y₂ · ∂y₂/∂h ← 中间变量的梯度
∂L/∂W₁ = ∂L/∂h · ∂h/∂W₁ ← 再用中间梯度算第一层的梯度
直观理解：前向是「数据流 →」，反向是「梯度流 ←」。
每一层收到来自上一层的梯度后，乘上自己对 W 的局部导数，得到 W 的最终梯度。
这个梯度 ∇W 告诉模型：「W 往正方向调一点，Loss 变大/变小多少？」
然后更新步骤就朝反方向走：让 Loss 变小的方向。
③ 参数更新 — SGD / Adam
SGD（随机梯度下降）
W = W − lr · ∂L/∂W
从当前 W 出发，沿着梯度的反方向（使 Loss 下降的方向）迈一小步。
lr（学习率）控制步长：太大一步跨过头（震荡/发散），太小走太慢。
每个 batch 的梯度是基于当前这 256 张图算的，不是全量 60000 张 → 有噪声（所以叫「随机」），但噪声反而有正则化效果。

Adam（自适应矩估计）
m = β₁·m + (1−β₁)·∇W
v = β₂·v + (1−β₂)·(∇W)²
W = W − lr · m / (√v + ε)
m：梯度的一阶矩（动量），记录梯度之前的方向，平滑震荡
v：梯度的二阶矩（自适应学习率），频繁更新的参数步长自动变小，稀疏更新的参数步长自动变大
对比：SGD 对所有参数用同一个 lr，Adam 给每个参数自动调整步长。Adam 对新手工匠更友好。
④ 评估 — Accuracy
Accuracy = 预测正确的样本数 ÷ 总样本数
对测试集 10000 张图，每张：
  ① 前向传播得到 10 个类别得分
  ② 取得分最高的类别作为预测结果
  ③ 对比预测 vs 真实标签
关键区别：评估阶段 不计算梯度、不更新参数，只做前向传播。
Accuracy 反映模型在「从未见过的数据」上的泛化能力。
它和 Loss 是互补指标：Loss 衡量单个样本的犯错程度，Accuracy 衡量整体的正确率。
